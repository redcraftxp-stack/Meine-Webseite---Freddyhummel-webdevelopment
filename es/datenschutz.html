2. Información general sobre el tratamiento de datos

Trato los datos personales de acuerdo con las disposiciones legales aplicables en materia de protección de datos, en particular el Reglamento General de Protección de Datos (RGPD).

Los datos personales son cualquier información que permita identificar directa o indirectamente a una persona física.

3. Acceso al sitio web y archivos de registro del servidor

Cuando visita este sitio web, el proveedor de alojamiento puede recopilar automáticamente información técnica y almacenarla en archivos de registro del servidor.

Esta información puede incluir:

  • Dirección IP del dispositivo
  • Fecha y hora del acceso
  • Página o archivo solicitado
  • Dirección desde la que se accedió al sitio web
  • Navegador y sistema operativo utilizados

Estos datos se utilizan para garantizar el funcionamiento técnico, la seguridad y la estabilidad del sitio web. No se combinan intencionadamente con otros datos personales.

4. Alojamiento web y servicios técnicos

Este sitio web utiliza servicios técnicos de alojamiento y distribución de contenido para poder ofrecer sus páginas de forma segura y rápida. En este contexto, los proveedores técnicos pueden tratar datos personales, como direcciones IP y datos de acceso.

El tratamiento se realiza para garantizar el funcionamiento del sitio, protegerlo frente a ataques y mejorar su disponibilidad.

Los datos se tratarán conforme a las disposiciones legales aplicables y, cuando sea necesario, sobre la base de un contrato de tratamiento de datos.

5. Contacto mediante formulario, correo electrónico o teléfono

Si se pone en contacto conmigo mediante el formulario de contacto, correo electrónico o teléfono, trataré los datos que facilite para responder a su consulta.

Estos datos pueden incluir:

  • Nombre
  • Dirección de correo electrónico
  • Número de teléfono, si lo facilita
  • Contenido de su mensaje

Utilizo estos datos exclusivamente para gestionar su consulta, comunicarme con usted y, si procede, preparar una oferta.

No transmito estos datos a terceros sin una base jurídica válida o sin su consentimiento, salvo que exista una obligación legal.

6. Opiniones y reseñas

Si envía una reseña a través de este sitio web, se pueden recopilar el nombre que indique, la valoración seleccionada y el texto de su opinión.

Las reseñas se revisan antes de su publicación. Una vez aprobadas, pueden mostrarse públicamente en el sitio web.

No incluya información personal sensible ni datos de otras personas en el texto de su reseña.

7. Asistente de inteligencia artificial

Este sitio web puede ofrecer un asistente basado en inteligencia artificial para responder preguntas sobre los servicios y ayudar a describir un proyecto web.

Si utiliza esta función, los mensajes que introduzca pueden transmitirse a un servicio técnico externo para generar respuestas. Por ello, no introduzca contraseñas, datos bancarios ni información personal sensible.

Los datos se tratarán únicamente en la medida necesaria para proporcionar la función solicitada y de acuerdo con las condiciones del proveedor correspondiente.

8. Cookies y tecnologías similares

Este sitio web puede utilizar tecnologías técnicas necesarias para su funcionamiento y seguridad.

Si se utilizan cookies o tecnologías similares que requieren consentimiento, se solicitará dicho consentimiento antes de activarlas, de acuerdo con la normativa aplicable.

9. Destinatarios de los datos

Para prestar los servicios del sitio web pueden intervenir proveedores técnicos, por ejemplo, servicios de alojamiento, procesamiento de formularios o servicios de inteligencia artificial.

Estos proveedores solo reciben los datos necesarios para realizar sus funciones. Cuando corresponda, se formalizan los acuerdos de tratamiento de datos exigidos por la legislación.

10. Transferencias internacionales de datos

Algunos proveedores técnicos pueden tratar datos fuera del Espacio Económico Europeo. En esos casos, las transferencias se realizarán únicamente cuando exista una base jurídica válida y se cumplan los requisitos del RGPD, por ejemplo, mediante una decisión de adecuación o garantías apropiadas.

11. Duración del almacenamiento

Los datos personales se almacenan únicamente durante el tiempo necesario para cumplir la finalidad correspondiente o durante el plazo exigido por la legislación.

Cuando los datos dejan de ser necesarios y no existe una obligación legal de conservarlos, se eliminan o se anonimizan.

12. Sus derechos

De acuerdo con el RGPD, usted puede tener los siguientes derechos:

  • Derecho de acceso a sus datos personales
  • Derecho de rectificación de datos incorrectos
  • Derecho de supresión de sus datos
  • Derecho a la limitación del tratamiento
  • Derecho a la portabilidad de los datos
  • Derecho de oposición al tratamiento
  • Derecho a retirar un consentimiento previamente otorgado

Para ejercer sus derechos, puede ponerse en contacto conmigo mediante los datos indicados anteriormente.

13. Derecho a presentar una reclamación

También tiene derecho a presentar una reclamación ante una autoridad de control de protección de datos si considera que el tratamiento de sus datos personales infringe la legislación aplicable.

14. Seguridad de los datos

Utilizo medidas técnicas y organizativas razonables para proteger los datos personales frente a pérdidas, accesos no autorizados, modificaciones o divulgaciones indebidas.

15. Modificaciones de esta política de privacidad

Esta política de privacidad puede actualizarse cuando cambien las funciones del sitio web, los servicios utilizados o los requisitos legales.
